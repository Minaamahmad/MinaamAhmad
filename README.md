### Featured Projects

#### 🃏 [Capture Cards](https://github.com/Minaamahmad/game)
*Real-time multiplayer card game built with a server-authoritative architecture.*
- Implemented deterministic server-side state resolution to prevent desyncs and illegal moves.
- Reduced network latency with Socket.io event broadcasting and event payload validation.
- Built cross-platform clients using Next.js and React Native.

#### 🏨 [Prime Booking](https://github.com/Minaamahmad)
*Full-stack hotel management and reservation platform.*
- Configured multi-origin secure cookie management (SameSite/Secure/CORS) via Google OAuth & JWT.
- Designed role-based access control (RBAC) separating guest reservations from owner management.
- Integrated real-time messaging and availability updates using WebSockets.

#### 🤖 [Autobot](https://github.com/Minaamahmad)
*Automated media processing and cross-platform publishing microservice.*
- Engineered a decoupled ingestion pipeline using Node.js, `yt-dlp`, and Redis-backed queues.
- Handled scheduled distribution to Meta Graph APIs with resilient retry logic.
- Containerized the runtime in Docker to isolate cookie sessions and external binary dependencies.
